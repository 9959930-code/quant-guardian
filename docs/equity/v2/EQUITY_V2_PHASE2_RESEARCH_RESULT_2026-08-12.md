## 1. 연구 개요

1차 연구의 공격형·균형형 TQQQ 전략을 중심으로 다음 조건을 더 촘촘하게 탐색했다.

```text
공격형:
QQQ 장기 상승추세
+ 52주 고점 대비 3~15% 눌림
+ 10·20·50일선 회복
+ 15~30% 추적청산

균형형:
QQQ 150·180·200·220일선 위
+ 10·20·30·55·63·90일 고점 돌파
+ 180·200·220일선 이탈 청산

공통:
주간·월간 판단
1·2·3회 분할
TQQQ 50·75·100%
잔여 비중 QQQ 또는 CASH
1·2회 신호 확인
```

- 광범위 후보: **36,288개**
- 정상 계산: **35,424개**
- 다음 거래일 시가 정밀검증: **250개**
- 비용: 수수료 5bp + 슬리피지 5bp
- 선택 폴드: 2010~2014, 2015~2018, 2019~2022
- 홀드아웃: 2023~2026, 후보 선택에는 사용하지 않고 보고만 함

## 2. 2차 공격형

```text
판단: 월말

진입:
- QQQ가 220일선 위
- 220일선이 20거래일 전보다 상승
- QQQ가 52주 고점 대비 7.5% 이상 조정
- QQQ가 10일선을 회복
- 2개월에 걸쳐 TQQQ 50% → 100%

보유:
- 중간 리밸런싱 없음

청산:
- 진입 후 QQQ 최고점 대비 20% 하락을 월말에 확인
- 2개월에 걸쳐 TQQQ 50% → 0%
```

| 항목 | 결과 |
|---|---:|
| 전체 CAGR | **40.17%** |
| 전체 MDD | **-69.92%** |
| 개발 3개 폴드 평균 CAGR | 40.80% |
| 개발 폴드 최저 CAGR | 23.22% |
| 홀드아웃 CAGR | 36.54% |
| 홀드아웃 MDD | -58.04% |
| 평균 TQQQ 노출 | 88.05% |
| 전체 체결 이벤트 | 6회 |
| 연간 체결 이벤트 | 약 0.36회 |
| 1,000만원 단순 비례 최종액 | **약 25억 8,289만원** |

1차 공격형보다 CAGR은 낮아졌지만, 세 개발 폴드에서의 반복성을 우선한 결과다. 여전히 사실상 TQQQ 장기보유에 가까워 기본 실전후보보다는 초공격 비교후보로 보는 것이 맞다.

## 3. 2차 균형형

```text
판단: 월말

진입:
- QQQ가 180일선 위
- QQQ가 직전 20거래일 고점을 돌파
- 다음 거래일 시가에 TQQQ 100% 진입

보유:
- 중간 리밸런싱 없음

청산:
- 월말 QQQ가 200일선 아래
- 다음 거래일 시가에 TQQQ 전량 청산
- 대기자금은 CASH
```

| 항목 | 결과 |
|---|---:|
| 전체 CAGR | **32.27%** |
| 전체 MDD | **-44.72%** |
| 개발 3개 폴드 평균 CAGR | 32.94% |
| 개발 폴드 최저 CAGR | 29.14% |
| 개발 최악 MDD | -44.72% |
| 홀드아웃 CAGR | 29.79% |
| 홀드아웃 MDD | -42.87% |
| 평균 TQQQ 노출 | 65.08% |

1차 균형형과 거의 같은 구조가 다시 선택됐다. 200일선은 청산선으로 유지됐고, 진입 장기필터만 200일선에서 180일선으로 조금 완화됐다.

## 4. 두 전략 혼합

두 전략은 같은 TQQQ를 사용하므로 자산분산이 아니라 **진입·청산 타이밍 분산**이다. 혼합비율은 10% 단위로, 리밸런싱은 다음을 비교했다.

```text
- 무리밸런싱
- 연 1회
- 매월 확인 후 목표비율에서 10·15·20%포인트 이탈 시 리밸런싱
```

전략 간 자금이동에는 10bp 비용을 적용했다.

### 가장 높은 개발구간 선택점수 및 MDD -50% 후보

```text
공격형 50% + 균형형 50%
매월 비중 확인
공격형 실제 비중이 목표 50%에서 10%포인트 이상 벗어나면 50:50으로 복원
```

## 7. 2008년 합성 TQQQ 스트레스

TQQQ는 2010년에 상장됐으므로 2008년 실제 기록이 없다. QQQ의 일일수익률을 3배로 복리 계산하고 연간 드래그를 1·2.5·4% 적용한 합성 스트레스를 별도로 계산했다.

### 연간 드래그 2.5% 대표값

| 전략 | 전체 CAGR | 전체 MDD | 2007~2009 수익률 | 2007~2009 MDD |
|---|---:|---:|---:|---:|
| 합성 TQQQ 단순보유 | 29.18% | **-94.44%** | -39.59% CAGR | **-94.44%** |
| 공격형 | 27.73% | **-84.17%** | -43.01% CAGR | **-84.17%** |
| 균형형 | 25.48% | **-66.17%** | -0.71% CAGR | **-66.17%** |
| 50:50·10%p 이탈 혼합 | **29.02%** | **-74.51%** | 누적 -43.97% | **-74.51%** |
| 40:60·10%p 이탈 혼합 | 28.80% | **-72.89%** | 누적 -36.38% | **-72.89%** |

따라서 2010년 이후 실제자료에서 나온 `혼합 MDD 약 -46~-48%`는 2008년 같은 금융위기에서도 유지되는 보장이 없다. 두 혼합전략 모두 같은 TQQQ를 사용하기 때문에 극단적 위기에서는 -70%대 MDD가 가능했다.

실제로 위기 MDD를 -50% 부근으로 제한하려면 공격형·균형형의 비율만 조절하는 것으로는 부족하고, 다음 중 하나가 필요하다.

```text
- TQQQ 목표비중 자체를 50~75%로 낮추고 나머지를 QQQ/CASH로 둠
- 일부를 QLD로 대체
- 더 빠른 장기추세 청산조건을 사용
```

## 8. 최종 판단

### 수익과 MDD의 균형을 우선한다면

```text
1순위 연구후보:
공격형 50% + 균형형 50%
매월 비중 확인
10%포인트 이탈 시 50:50 복원

실제 2010~2026:
CAGR 38.88%
MDD -47.87%

2008 합성 스트레스:
MDD 약 -74.5%
```

### 위험조정성과를 조금 더 우선한다면

```text
공격형 40% + 균형형 60%
10%포인트 이탈 시 복원

실제 2010~2026:
CAGR 38.19%
MDD -46.04%
Calmar 0.829

2008 합성 스트레스:
MDD 약 -72.9%
```

### 최종자산만 우선한다면

실제 2010년 이후 결과에서는 TQQQ 단순보유가 가장 높았다. 그러나 MDD -81.66%, 합성 금융위기 MDD 약 -94%를 감수해야 한다.

현재 단계에서는 **50:50·10%포인트 이탈 리밸런싱을 주력 후보**, **40:60을 위험조정 비교후보**, **TQQQ 단순보유를 수익상한 벤치마크**로 유지하는 것이 적절하다. 실제 Telegram 적용 전에는 시작자금·현재 보유량·월말 신호 실행방식·세금과 환전비용을 확정하고 Shadow 운영을 거쳐야 한다.
