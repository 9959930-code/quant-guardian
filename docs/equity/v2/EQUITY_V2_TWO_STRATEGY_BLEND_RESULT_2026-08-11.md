# Equity v2 공격형·균형형 혼합 연구 결과

- 기준일: 2026-08-11
- 기간: 2010-03-01~2026-08-11
- 가격: 실제 TQQQ·QQQ 조정 OHLC
- 체결: 신호 다음 거래일 시가
- 비용: 수수료 5bp + 슬리피지 5bp
- 상태: 연구 전용 / 실전·Telegram 미반영
- BTC 파트: 변경 없음

## 두 전략

### 공격형

```text
QQQ 장기상승 중 52주 고점 대비 5% 이상 조정
+ 월말 20일선 회복
→ TQQQ 100% 진입

월말 기준 진입 이후 최고점 대비 20% 하락
→ TQQQ 전량 청산
```

### 균형형

```text
QQQ 월말 20거래일 고점 돌파
+ QQQ 200일선 위
→ TQQQ 100% 진입

QQQ 월말 200일선 아래
→ TQQQ 전량 청산
```

두 전략 일간 수익률 상관계수는 `0.720`이었다. 같은 TQQQ를 사용하므로 자산분산이라기보다 진입·청산 타이밍 분산이다.

## 판단

### 위험한도 약 -50%를 유지하려면

```text
권장 1:
공격형 25% + 균형형 75%
연 1회 리밸런싱
CAGR 36.69%, MDD -43.66%, Calmar 0.840

권장 2:
공격형 50% + 균형형 50%
연 1회 리밸런싱
CAGR 40.09%, MDD -48.45%, Calmar 0.827
```

25:75는 위험조정성과가 가장 좋았고, 50:50은 MDD -50% 부근에서 절대수익을 더 높였다. 공격형을 75% 이상 두면 MDD가 -56% 이상으로 커졌다.

### 중요한 한계

- 두 전략 모두 TQQQ이므로 동시에 보유할 때 계좌는 TQQQ 100%가 된다.
- TQQQ 실제 이력은 2010년부터라 2008년 금융위기가 없다.
- 후보를 과거 데이터에서 찾은 뒤 혼합비율을 비교한 후속 연구다.
- 세금·환전비용·개인 계좌 상태는 제외했다.
- 다음 단계에서는 합성 3배 나스닥으로 2008년 스트레스, 비용 2배, 체결지연, 월말 신호 확인 방식을 비교해야 한다.
