## 7. 복잡한 타이밍 전략은 왜 최종후보에서 빠졌나

정밀 과세계좌 후보 중 가장 높은 동적전략의 예시는 다음과 같다.

```text
QQQ가 52주 고점 대비 25% 하락
+ 20일선 회복
→ TQQQ 진입
→ 이후 고점 대비 20% 추적청산
```

| 항목 | 결과 |
|---|---:|
| 개발 평균 세후 XIRR | 18.63% |
| 개발 최저 세후 XIRR | **0.15%** |
| 개발 최악 MDD | -57.12% |
| 전체 세후 XIRR | 29.57% |
| 전체 MDD | -65.39% |
| 홀드아웃 세후 XIRR | 15.25% |

전체기간 숫자는 높았지만 한 개발구간에서 거의 수익이 없었고 홀드아웃 성과도 크게 낮았다. 복잡한 타이밍 후보 다수가 비슷하게 특정 국면에 의존했다. 현대시장 기준에서는 단순 고정배분·정기 리밸런싱이 더 반복적이었다.

## 10. 핵심 결론

1. 2006년 이후 현대시장에 우선 가중하면 복잡한 저점·고점 타이밍보다 단순 고정배분이 더 강건했다.
2. 반복성 우선 고수익형은 QLD 100%였다.
3. 사용자처럼 높은 위험을 감수한다면 TQQQ 50% + QQQ 50%를 연 1회 리밸런싱하는 조합이 전체 수익률은 더 높았다.
4. 위험과 수익의 균형은 QLD 50% + QQQ 50% 연 1회가 가장 좋았다.
5. TQQQ 100%는 최종자산 상한은 높지만 금융위기 경로와 시작시점 위험 때문에 기본전략으로 권장하기 어렵다.
6. 금·장기채는 이번 최종후보에 포함되지 않았다. 현대구간 수익률을 높이는 데 고정편입 효과가 뚜렷하지 않았다.
7. 실제 적용 전에는 과세계좌에서 연 1회 리밸런싱 시 발생하는 양도세와 현재 보유상태를 반영한 Shadow 운영이 필요하다.
