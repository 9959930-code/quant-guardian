# Quant Guardian 지수 타이밍 PRD

## 1. 제품 목적

미국 지수·섹터 ETF의 마감 가격을 이용해 사용자가 다음 세 가지를 매일 한 화면에서 판단하도록 돕는다.

1. 지금 신규매수, 분할매수, 보유, 비중축소, 매도·대기 중 무엇을 검토할지
2. 전체 투자 가능 금액 중 주식형 ETF를 몇 %까지 보유할지
3. 어떤 객관적 가격 조건이 충족되면 다음 매수 또는 축소를 실행할지

목표는 단기 고점과 저점을 정확히 예측하는 것이 아니다. 큰 하락 추세에서 노출을 줄이고 상승 추세에 규칙적으로 참여해 장기 위험조정수익을 개선하는 것이 목적이다.

## 2. 대상 사용자

- 미국 ETF 투자를 직접 주문하는 개인 투자자 1명
- 보조지표와 퀀트 용어에 익숙하지 않아 한글 행동 지침이 필요한 사용자
- 자동주문보다 매일 갱신되는 의사결정 보조 자료를 원하는 사용자

## 3. 대상 자산

- 핵심 지수: SPY, QQQ, SPYG
- 섹터 보조: XLK, SMH
- 대기·분산: SGOV, GLD, TLT
- 장기 백테스트 대기자금 대용: SHY
- 실행 표시 대안: SPY → SPYM, QQQ → QQQM

개별주 추천, 커뮤니티 포트폴리오 추적, 자동주문은 제품 범위에서 제외한다.

## 4. 핵심 기능

### 4.1 매일 판단

- 미국장 마감 일봉으로 지표를 계산한다.
- 결과를 `신규매수 검토`, `분할매수`, `보유·관찰`, `비중축소`, `매도·대기`로 표시한다.
- 우선 확인 ETF와 실제 매수 표시 종목을 구분한다.
- 실행 조건과 보류 조건을 한글 문장으로 제공한다.

### 4.2 보조지표 검토

- 추세: SMA 20/50/100/200, EMA 12/26, MACD, 일목균형표, ADX
- 모멘텀: 1/3/6/12개월 수익률, 12-1개월 모멘텀, SPY 대비 상대강도
- 진입 타이밍: RSI, 스토캐스틱, 볼린저밴드, ATR 이격, Donchian 20일 돌파, 거래량, OBV
- 위험: 63일 변동성, 1년 최대낙폭, ATR 비율, VIX
- 같은 가격에서 파생된 지표의 중복 확신을 막기 위해 네 묶음별 점수 상한을 둔다.

### 4.3 목표 포트폴리오

- 오늘 판단에 따라 주식형 목표 비중을 0%, 50%, 75%, 90%, 100% 중 하나로 정한다.
- 주식형은 상위 두 ETF로 구성하되 적어도 하나는 핵심 지수로 한다.
- 섹터 ETF는 전체 투자 가능 금액의 50%를 넘지 못한다.
- GLD와 TLT는 각 자산 자체의 200일선과 점수 조건을 통과할 때만 사용한다.
- 조건을 통과하지 못한 비중은 SGOV로 이동한다.

### 4.4 금액 계산

- 웹에서 총 투자 가능 금액을 입력하면 목표 비중을 원화 목표 평가액으로 환산한다.
- 입력 금액은 브라우저 로컬 저장소에만 저장한다.
- 현재 보유량은 입력받지 않으므로 주문액이 아니라 목표 평가액임을 명시한다.

### 4.5 텔레그램

- 기준일, 오늘 할 일, 주식형 목표 비중, 우선 ETF, 실행 시점, 판단 근거, 목표 보유 비중, 매도 기준을 한글로 보낸다.
- `PORTFOLIO_VALUE_KRW`가 설정된 경우에만 원화 목표 평가액을 포함한다.
- 자동주문이나 실시간 장중 신호로 오해할 표현을 사용하지 않는다.

### 4.6 백테스트

- 월말까지 확인된 신호를 다음 달 수익률에 적용한다.
- 매매 회전율에 설정된 거래비용을 차감한다.
- SPY와 QQQ의 CAGR, MDD, Sharpe 등과 같은 구간으로 비교한다.
- 현재 진행 중인 불완전한 달은 결과에서 제외한다.

## 5. 성공 기준

- 웹과 텔레그램에 예전 시장 상태 용어가 노출되지 않는다.
- 모든 목표 비중의 합은 100%다.
- 섹터 ETF 비중은 전체의 50% 이하다.
- 하락 장기추세의 ETF에 신규매수 신호가 나오지 않는다.
- 총 투자금은 외부로 전송되지 않는다.
- 자동 테스트가 GitHub 배포 전에 통과한다.
- 백테스트 수익률만 단독으로 강조하지 않고 MDD와 벤치마크를 함께 표시한다.

## 6. 범위 밖

- 실시간 시세와 틱 데이터
- 증권사 주문 API와 자동매매
- 환율·한국 세금의 개인별 자동 계산
- 사용자의 실제 보유 종목 동기화
- 수익 보장 또는 매수 적중 확률 제공

## 7. 미정 사항

- 실제 총 투자 가능 금액
- 사용자가 감내할 수 있는 최대 손실률
- 투자 계좌 종류와 적용 세금
- 텔레그램을 매일 받을지 신호 변경일에만 받을지
- 실제 보유량 입력 기능의 필요 여부
