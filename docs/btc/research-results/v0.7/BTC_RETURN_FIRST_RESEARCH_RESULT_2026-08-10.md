# BTC 수익률 우선 최적화 연구 결과 v0.7

- 기준일: 2026-08-10
- 연구기간: 2016-01-01~2026-08-08
- 초기자금 예시: 10,000,000원
- 상태: 과거 연구 완료 / 실전·웹·Telegram 미승인
- 자동주문: 없음

## 1. 연구 목적

v0.6은 전체기간·Upbit 기간·완료 반감기 사이클의 위험조정성과를 우선하면서 v0.5보다 CAGR이 낮아졌다. v0.7은 목적함수를 다음처럼 변경했다.

```text
최대화:
min(2016년 이후 전체 CAGR, 실제 Upbit 중첩기간 CAGR)

필수 위험문턱:
전체기간 MDD >= -50%
Upbit 중첩기간 MDD >= -50%
각 완료 반감기 epoch MDD >= -50%
```

롱온리, 무레버리지, 무공매도, 실제 block-height 반감기 진행률 필수, 일요일 UTC 확정 신호의 다음 일봉 시가 체결, 수수료 5bps와 슬리피지 10bps를 적용했다.

## 2. 탐색 범위

총 3,960개 후보를 계산하고, 전체기간 MDD 문턱을 통과한 고수익 후보 350개를 실제 Upbit 가격과 완료 반감기 사이클로 재검증했다.

- 반감기 전 매수 시작: 이전 epoch 진행률 60~85%
- 반감기 후 보유 종료: 새 epoch 진행률 30~50%
- 비중 방식: 100% 또는 63일 변동성 기준 40~60% 위험예산
- 데드밴드: 10%p 또는 15%p
- 리밸런싱: 이전 목표비중 또는 실제 평가비중
- 동적 매도 후보: 40주선 또는 40주선·200일선·180일 모멘텀 중 2개
- 추세약화 확인기간: 1~3주
- 상승추세에서는 100%를 허용하고 약세에서만 위험을 줄이는 비대칭 후보 포함

## 3. 공격형 연구 후보

```text
candidate_id:
window_pre65_post35_vol45_db10_actual

매수·보유 구간:
이전 반감기 epoch 진행률 65%부터
새 반감기 epoch 진행률 35%까지

비중:
min(100%, 45% / 최근 63일 연환산 변동성)

리밸런싱:
실제 BTC 평가비중과 목표비중 차이가 10%p 이상일 때
다음 일봉 시가에 조정
```

10분당 1블록으로 단순 환산하면 반감기 약 17개월 전부터 약 17개월 후까지에 가까우나, 실제 프로그램은 날짜가 아니라 block progress를 사용한다.

## 4. 위험여유가 조금 더 있는 후보

```text
window_pre65_post35_vol40_db10_actual
```

| 구분 | CAGR | MDD |
|---|---:|---:|
| 전체기간 | **66.27%** | **-42.28%** |
| Upbit 중첩 | **63.45%** | **-48.37%** |

공격형보다 전체 CAGR은 약 4.62%p 낮지만 전체기간 MDD 여유가 더 크다. 다만 Upbit MDD는 여전히 -50%에 가깝다.

또 다른 인접 후보인 `window_pre65_post35_vol40_db10_target`은 전체 CAGR 66.92%, MDD -44.83%, Upbit CAGR 65.29%, MDD -48.17%였다.

## 9. 중요한 한계

1. v0.3~v0.6 결과를 본 뒤 3,960개 후보를 같은 과거자료에서 탐색했으므로 선택 편향이 크다.
2. Upbit 기간은 전체기간과 일부 겹치므로 완전히 독립된 표본외 검증이 아니다.
3. 완료된 독립 반감기 사이클은 Epoch 2와 3 두 개뿐이다.
4. 2024년 반감기 이후 현재 사이클은 아직 완료되지 않았다.
5. 공격형의 Upbit MDD -49.79%는 위험한도에 지나치게 가깝다.
6. 70.89% CAGR은 미래 기대수익률이 아니다.

따라서 실전 후보로 바로 고정하지 않고 다음 세 후보를 동일 시점에 전향 기록하는 것이 적절하다.

```text
A. v0.7 공격형: pre65→post35, vol45, 실제비중
B. v0.7 위험균형형: pre65→post35, vol40
C. v0.5 무반감기 기준선
```

30개 확정 일봉은 시스템 작동검증에 사용하고, 전략 성과는 최소 26주, 가능하면 52주 이상 규칙을 바꾸지 않은 기록으로 추가 평가한다.
