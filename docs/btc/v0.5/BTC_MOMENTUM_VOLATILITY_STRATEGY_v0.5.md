# BTC 모멘텀·변동성 전략 v0.5 설명

## 한 문장 설명

여러 보조지표로 고점과 저점을 맞히는 대신, **1·3·6·12개월 가격 방향의
합의로 BTC 기본비중을 정하고 최근 변동성이 높으면 그 비중을 낮추는** 주간
롱온리 전략이다.

## 매주 계산하는 값

매주 일요일 UTC 확정 종가로 다음 네 수익률을 계산한다.

```text
30일 수익률   ≈ 1개월
90일 수익률   ≈ 3개월
180일 수익률  ≈ 6개월
365일 수익률  ≈ 12개월
```

각 수익률이 0%보다 높으면 1점을 부여한다.

| 양수인 기간 | 모멘텀 기본비중 |
|---:|---:|
| 0개 | BTC 0% |
| 1개 | BTC 25% |
| 2개 | BTC 50% |
| 3개 | BTC 75% |
| 4개 | BTC 100% |

하나의 이동평균선이 늦게 꺾이는 문제를 줄이기 위해 서로 다른 속도의 가격
추세 네 개를 동일하게 사용한다.

## 변동성 예산

최근 63일 일간수익률의 표준편차를 연환산하고 목표 위험을 45%로 둔다.

```text
변동성 허용비중 = 45% / 최근 63일 연환산 변동성
최종 목표비중 = min(모멘텀 기본비중, 변동성 허용비중, 100%)
```

예를 들어 네 모멘텀이 모두 양수여도 최근 변동성이 90%라면 변동성 허용비중은
`45% / 90% = 50%`이므로 최종 BTC 목표비중은 50%다. 목표변동성 45%는
예상수익률 45%라는 뜻이 아니라 포트폴리오 위험을 조절하기 위한 숫자다.

## 실제 비중 변경

- 일요일 확정 신호만 사용한다.
- 기존 비중과 새 목표비중이 10%포인트 이상 차이 날 때만 조정한다.
- 네 모멘텀이 모두 0% 이하이면 차이와 관계없이 목표비중을 0%로 둔다.
- 신호 다음 UTC 일봉 시가에 체결된 것으로 계산한다.
- BTC 공매도와 레버리지는 사용하지 않는다.
- 남는 비중은 현금이며 이번 연구에서는 현금 이자를 0%로 계산한다.

## 사용하지 않는 지표

반감기, MVRV, RSI, 일목균형표, 김치 프리미엄은 v0.5의 매수·매도 비중을
결정하지 않는다. 반감기 epoch는 결과를 구간별로 비교하는 데만 사용한다.
지표를 많이 넣어 과거 데이터에 맞추는 위험을 줄이기 위한 선택이다.

## 학술적 배경과 한계

- Moskowitz, Ooi, Pedersen의 [Time Series Momentum](https://w4.stern.nyu.edu/facdir/lpederse/papers/TimeSeriesMomentum.pdf)은 여러 자산에서 1~12개월 추세 지속성을 연구했다.
- Liu와 Tsyvinski의 [Risks and Returns of Cryptocurrency](https://www.nber.org/papers/w24877)은 암호화폐의 시계열 모멘텀을 보고했다.
- Moreira와 Muir의 [Volatility-Managed Portfolios](https://www.nber.org/papers/w22208)은 변동성이 높을 때 위험을 줄이는 방법을 연구했다.
- 반면 [Cryptocurrencies and Momentum](https://www.sciencedirect.com/science/article/pii/S0165176519301077)과 [On the Performance of Volatility-Managed Portfolios](https://www.sciencedirect.com/science/article/abs/pii/S0304405X2030132X)는 모멘텀·변동성 관리가 모든 표본외 구간에서 우월하지 않다는 반대 증거를 제공한다.

학술적 근거는 전략의 수익을 보장하지 않는다. 특히 v0.5는 v0.3·v0.4의 실패를
본 뒤 만든 규칙이므로 2016~현재 결과는 순수한 표본외 검증이 아니다.
