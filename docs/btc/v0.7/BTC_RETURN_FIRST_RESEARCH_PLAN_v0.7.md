# BTC 수익률 우선 최적화 연구계획 v0.7

- 기준일: 2026-08-10
- 상태: 연구 실행 전 / 실전 미승인
- 자동주문: 없음
- 기반: v0.6 연구 브랜치

## 목적

v0.6은 MDD와 사이클별 강건성을 우선해 v0.5보다 CAGR이 낮아졌다. v0.7은 목적함수를 다음처럼 바꾼다.

```text
최대화:
min(2016년 이후 전체 CAGR, 실제 Upbit 중첩기간 CAGR)

필수 제약:
전체 MDD >= -50%
Upbit 중첩 MDD >= -50%
각 완료 반감기 epoch MDD >= -50%
롱온리
레버리지·공매도 없음
반감기 진행률 필수
다음 일봉 시가 체결
수수료·슬리피지 반영
```

수익률이 높더라도 위 위험문턱을 넘으면 실전 후보에서 제외한다.

## 탐색 전략군

### 1. 반감기 고정 보유창

- 매수 시작: 이전 반감기 epoch 진행률 60~85%
- 매도 종료: 새 epoch 진행률 30~50%
- 비중: 100% 또는 목표변동성 40~60% 상한
- 데드밴드: 10%p·15%p
- 리밸런싱: 이전 목표비중 또는 실제 평가비중

### 2. 반감기 + 추세기반 매도

- 반감기 전 진행률 65~75%에서 보유 시작
- 반감기 후 진행률 20~30%부터 매도조건 활성화
- 진행률 40~50%에서 최대 보유창 종료
- 추세: 40주선 또는 40주선·200일선·180일 모멘텀 중 2개 확인
- 확인기간: 1~3주
- 상승추세에서는 100% 유지하는 비대칭 변동성 방식 포함
- 추세약화 시 0%·25%·50%로 축소

총 후보는 2,500개 이상이며 전체기간에서 MDD 문턱을 통과한 상위 후보만 Upbit와 완료 사이클로 재검증한다.

## 비교 기준

- BTC 단순보유
- v0.5 모멘텀·변동성
- v0.6 반감기 확인형
- v0.7 공격형
- v0.7 완충형(MDD -45% 이내 후보)

## 강건성

최종 공격형 후보에 다음을 별도 적용한다.

- 비용 2배
- 체결 1일·2일 지연
- 데드밴드 ±5%p
- 대기현금 연 3%

## 해석 제한

v0.7은 v0.3~v0.6 결과를 본 뒤 같은 과거자료에서 넓은 후보를 탐색하므로 선택 편향이 크다. 완료 반감기 사이클도 적다. 따라서 높은 과거 CAGR이 나와도 실전 승인값이 아니며, 규칙을 고정한 Shadow 기록이 추가로 필요하다.
