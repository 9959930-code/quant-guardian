## 최종 목표비중

```text
보유구간:
반감기 epoch 진행률 65% 이상
또는 다음 epoch 진행률 35% 이하

보유구간 밖:
최종 BTC 목표비중 0%

보유구간 안:
최종 BTC 목표비중 = min(100%, 40% / 최근 63일 연환산 변동성)
```

## 3주 분할

최종 목표비중과 현재 실제비중 차이가 10%포인트 이상이거나, 최종 목표가 0%인데 BTC가 남아 있으면 3주 계획을 시작한다.

예시 1 — 0%에서 최종 75% 매수:

```text
1주차 월요일: 25%
2주차 월요일: 50%
3주차 월요일: 75%
```

예시 2 — 75%에서 최종 0% 매도:

```text
1주차 월요일: 50%
2주차 월요일: 25%
3주차 월요일: 0%
```

분할계획의 최종 목표는 시작 시 고정한다. 분할 중 새 주간 목표가 기존 최종목표와 10%포인트 이상 달라지거나 방향이 반전되면 기존 계획을 취소하고, 당시 실제비중에서 새 3주 계획을 시작한다.
