# BTC Fixed Six · Clock Hybrid 1.1 변경사항

## 변경 목적

기존 전략은 다음 epoch 35% 초과 뒤 세 번의 연속 월요일에 매도했다. Clock Hybrid 1.1은 35%를 사전경고로 분리하고 실제 매도를 36·37·38% 블록 임계값에 연결한다. 매수는 기존 65% 규칙을 유지한다.

## 수익률 연구 근거

고정 연구조건:

- Upbit KRW-BTC: 2017-09-25~2026-08-15
- 초기자금: 10,000,000원
- 편도 수수료 5bp + 슬리피지 10bp
- 임계블록 이후 첫 월요일 09:17 KST의 일봉 시가 근사

| 정책 | 최종액 | CAGR | MDD |
|---|---:|---:|---:|
| 기존 35% 후 3주 연속매도 | 1,245,677,204원 | 72.10% | -59.87% |
| 36·37·38% 블록매도 | 1,351,953,880원 | 73.69% | -59.87% |

역사상 후보는 최종자산 +8.53%, CAGR +1.59%포인트였다. 다만 완결된 Upbit 사이클이 두 개뿐이고, 미래에 35% 직후 급락하면 늦은 매도가 불리할 수 있다.

## 확정 규칙

```text
62.5%  저점 관찰 알림
65%    공식 월요일부터 BTC 1/3 → 2/3 → 100%
35%    고점 위험경고
36%    BTC 2/3 목표
37%    BTC 1/3 목표
38%    BTC 0% 목표
```

매도 2·3차는 이전 단계의 실제 잔고 동기화와 다음 임계값 도달을 모두 요구한다.

## 자금준비 알림

첫 매수 자금이 다른 계좌에 있을 수 있으므로, 예상 1차 매수일 약 5영업일 전과 3영업일 전에 알린다.

예상법:

```text
현재 블록부터 65%까지 남은 블록 × 10분
→ 예상 65% 도달시각
→ 그 뒤 첫 월요일 09:17 KST
```

주말만 제외한 근사치다. 블록속도 변화나 한국 공휴일 때문에 실제 일정과 차이가 날 수 있다. 메시지에는 예상일과 실제 남은 블록을 함께 표시한다.

## 체결 지연 대응

과거 민감도에서 1~3일 지연은 대체로 영향이 작았지만 매도 지연은 경로에 따라 크게 달라졌다. 운영 규칙은 다음과 같다.

- 24시간 경과: 최신 가격·잔고로 재계산
- 3일 경과: 오래된 주문안 주의
- 7일 경과: 기존 금액 사용 금지

`현재 금액 다시 계산`은 같은 목표비중으로 새 주문검토액을 만든다. `주문안 취소`는 단계를 완료하지 않고 다음 공식 점검까지 기다린다.

## 상태 마이그레이션

기존 실사용 상태를 초기화하지 않는다.

```text
schema 4 / btc-fixed-six-upbit-telegram-1.0
→ schema 5 / btc-fixed-six-clock-hybrid-1.1
```

계좌잔고, phase, 완료단계, pending sync, Telegram update ID, 감사로그를 보존한다. 알 수 없는 버전은 자동 초기화 대신 오류로 중단한다.

## 변경하지 않은 항목

- Upbit KRW-BTC 현물
- 시작예산·추가입금 처리
- 월요일 09:17 공식 점검
- 사용자 직접 주문
- 주문 후 잔고 동기화
- pending sync 차단
- 월간보고
- BTC·ISA 통합 Telegram 메뉴
- 자동주문 없음
