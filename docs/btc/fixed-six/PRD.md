# Quant Guardian BTC Fixed Six — PRD

- 기준일: 2026-08-11
- 상태: 사용자 승인 구현안
- 투자대상: Upbit `KRW-BTC` 현물
- 자동주문: 없음

## 1. 제품 목적

Quant Guardian BTC Fixed Six는 Bitcoin 반감기 블록 진행률만으로 넓은 매수·보유·매도 구간을 정하고, Telegram에서 사용자가 직접 Upbit 주문을 실행하도록 안내하는 개인용 투자 보조 시스템이다.

핵심 목표는 다음과 같다.

1. 반감기 사이클당 핵심 주문을 매수 3회·매도 3회로 제한한다.
2. 시작예산 10,000,000원을 기준으로 목표비중과 원화 주문 검토액을 함께 안내한다.
3. 명령어를 외우지 않아도 Telegram 한글 메뉴와 버튼으로 예산·추가입금·잔고 동기화를 처리한다.
4. 실제 주문은 사용자가 Upbit에서 직접 실행하고, 프로그램은 주문 API를 사용하지 않는다.
5. 평상시 알림은 최소화하고 실제 행동·반감기 이벤트·시스템 오류를 놓치지 않게 한다.

## 2. 확정 전략

```text
반감기 진행률 65% 도달
→ 다음 월요일 1차 매수: BTC 33.3%
→ 다음 주 월요일 2차 매수: BTC 66.7%
→ 다음 주 월요일 3차 매수: BTC 100%

보유 중 중간 리밸런싱 없음

다음 반감기 발생 후 새 epoch 진행률 35% 초과
→ 다음 월요일 1차 매도: BTC 66.7%
→ 다음 주 월요일 2차 매도: BTC 33.3%
→ 다음 주 월요일 3차 매도: BTC 0%
```

- 일요일 UTC 상태를 확인하고 다음 월요일 한국시간 09:17 전후에 행동을 안내한다.
- 레버리지·공매도·선물은 사용하지 않는다.
- 가격·RSI·MVRV·63일 변동성은 중간 매매조건으로 사용하지 않는다.
- 24시간 가격 급변 및 MDD 단계별 실시간 경보는 사용하지 않는다.

## 3. 예산과 추가입금

### 3.1 시작예산

- 기본 시작예산: `10,000,000원`
- 첫 매수 전에는 Telegram에서 변경 가능하다.
- 첫 매수 이후 시작예산은 잠그며, 증액은 추가입금 기능으로 처리한다.

### 3.2 추가입금

- 첫 매수 전: 다음 진입예산에 즉시 반영한다.
- 3주 분할매수 도중: 남은 매수 단계의 목표금액에 자동 반영한다.
- 3차 매수 완료 후 보유 중:
  - `현재 사이클에 적용`: 다음 월요일 보정매수 1회
  - `다음 사이클에 보관`: 현재 사이클에는 투자하지 않음
- 3주 분할매도 도중: 다음 사이클 대기자금으로만 보관한다.
- 모든 선택은 Telegram 한글 버튼과 최종 확인 버튼으로 처리한다.

## 4. 실제 잔고 동기화

각 주문 안내 후 Telegram에 다음 버튼을 표시한다.

- `주문 완료 · 잔고 동기화`
- `30분 뒤 다시 알림`

잔고 동기화는 다음 순서로 처리한다.

1. 사용자가 실제 Upbit BTC 수량 입력
2. 사용자가 실제 Upbit 원화잔액 입력
3. 프로그램이 확인 화면 표시
4. 사용자가 `확정` 버튼 선택
5. 다음 단계 금액을 실제 잔고 기준으로 계산

동기화가 완료되지 않으면:

- 30분 후 1회 재알림
- 이후 매일 09:17에 1회 재알림
- 다음 공식 매수·매도 단계는 보류

## 5. Telegram 사용자 경험

상시 한글 메뉴:

- `상태 보기`
- `추가입금`
- `잔고 동기화`
- `시작예산 변경`
- `대기 작업`
- `도움말`

`/apply_current`, `/reserve_next`, `/confirm` 같은 내부 명령어는 사용자 화면에 요구하지 않는다. 상태 변경은 버튼과 숫자 입력으로 처리한다.

## 6. 알림 주기

### 6.1 15분 점검

GitHub Actions가 매시 `02·17·32·47분`에 실행된다.

- Telegram 입력 확인
- 반감기 블록 진행률 확인
- 처리 대기 작업 재알림
- 데이터 오류·복구 확인

### 6.2 09:17 KST

Upbit UTC 일봉 경계인 09:00 이후 데이터 반영 시간을 두고 비정각 실행한다.

- 매일: 데이터·상태 점검, 정상 시 무알림
- 매주 월요일: 매수·매도 단계가 있을 때 행동 알림
- 매월 첫 번째 월요일: 월간 상태보고

### 6.3 즉시 또는 준실시간 알림

- 반감기 진행률 65% 도달 예고
- 실제 반감기 발생
- 다음 반감기 후 진행률 35% 통과 예고
- 데이터 오류 및 복구

## 7. 상태·성과 표시

`상태 보기`와 월간보고에서 다음을 표시한다.

- 총 납입원금
- 현재 평가액
- 원금 대비 손익·수익률
- 운용 고점 대비 현재 낙폭
- 운용 중 최대낙폭
- BTC 수량·평가액
- 원화잔액
- 다음 사이클 대기자금
- 현재 반감기 진행률과 다음 행동 기준

## 8. 제외 범위

- Upbit 자동주문
- Upbit 출금
- AI 자연어 해석 API
- 24시간 가격 급변 매매경보
- MDD 단계별 실시간 경보
- 보유 중 변동성 리밸런싱
- ETH 및 기타 코인

## 9. 인수 기준

1. 신규 상태가 10,000,000원·0 BTC로 생성된다.
2. 사이클당 기본 주문이 정확히 매수 3회·매도 3회다.
3. 주문 후 잔고 동기화 전에는 다음 단계가 진행되지 않는다.
4. 3차 매수 후 현재 사이클 추가입금은 다음 월요일 보정매수 1회로 처리된다.
5. 매도 중 추가입금은 다음 사이클 대기자금으로만 처리된다.
6. Telegram 명령어 암기 없이 한글 메뉴와 버튼으로 조작할 수 있다.
7. 허용된 `TELEGRAM_CHAT_ID` 외 입력은 무시한다.
8. 자동주문 API 호출이 존재하지 않는다.
9. 데이터 오류 시 새 행동을 차단하고 오류·복구 알림을 보낸다.
10. 기존 미국 ETF 기능의 회귀 테스트가 통과한다.
