## 자금준비 예상일의 의미

- 현재 블록 높이에서 `10분/블록`으로 65% 도달시각을 추정한다.
- 추정 도달시각 이후 첫 월요일 09:17 KST를 1차 매수 예정일로 본다.
- 한국 공휴일은 별도 달력 API 없이 주말만 제외하므로, 알림의 5·3영업일은 운영상 근사치다.
- 블록 생성속도가 변하면 예상일도 바뀔 수 있으며, 알림은 주문이 아니다.

## 상태 보호

기존 `schema 4 / btc-fixed-six-upbit-telegram-1.0` 상태는 schema 5로 마이그레이션한다. BTC 수량, 원화잔액, 납입원금, pending sync, Telegram update 위치와 감사로그는 보존한다. 알 수 없는 상태 버전은 자동 초기화하지 않고 오류로 중단한다.
